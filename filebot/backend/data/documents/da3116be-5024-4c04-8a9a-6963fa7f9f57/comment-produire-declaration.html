Comment produire une déclaration – Produire votre déclaration de TPS/TVH

Renseignez-vous sur les différentes façons de produire une déclaration et choisissez celle qui vous convient le mieux.

Production électronique obligatoire

Si vous êtes inscrit à la TPS/TVH et que votre période de déclaration commence en 2024 ou plus tard, vous devez produire vos déclarations par voie électronique (sauf pour les organismes de bienfaisance et les institutions financières désignées particulières). Si vous ne le faites pas, nous vous imposerons une pénalité.

Pour en savoir plus : Exigences en matière de production électronique obligatoire et exceptions

Méthodes de production

Compte de l’ARC

Produisez votre déclaration de TPS/TVH directement dans votre compte de l’ARC (Mon dossier d’entreprise ou Représenter un client) à l’aide du service IMPÔTNET TPS/TVH intégré.

Vous pouvez soit :

  • Apprendre comment produire

    Dans votre compte de l’ARC

  • Produire maintenant

    Connectez-vous à votre compte de l’ARC

Formulaire IMPÔTNET TPS/TVH

Si vous n’avez pas de compte de l’ARC (Mon dossier d’entreprise ou Représenter un client), vous pouvez produire votre déclaration de TPS/TVH en ligne en utilisant le formulaire IMPÔTNET.

Cette méthode nécessite un code d’accès pour la TPS/TVH.

Vous pouvez :

  • Apprendre comment produire

    En utilisant le formulaire IMPÔTNET

  • Produire maintenant

    Produisez votre déclaration en utilisant le formulaire IMPÔTNET

Institution financière

Vous pouvez produire votre déclaration et verser votre TPS/TVH en ligne par l’intermédiaire d’une institution financière canadienne participante au moyen de l’échange électronique de données.

Apprendre comment produire

Par l’intermédiaire d’une institution financière

Logiciel de comptabilité tiers

Vous pouvez préparer votre déclaration de TPS/TVH à l’aide d’un logiciel de comptabilité tiers et la transmettre directement à l’Agence du revenu du Canada (ARC) à l’aide du Transfert de fichiers TPS/TVH par Internet.

Cette méthode nécessite un code d’accès pour la TPS/TVH .

Vous pouvez :

  • Apprendre comment produire

    En utilisant un logiciel de comptabilité tiers

  • Produire maintenant

    Téléchargez votre déclaration à l’aide du Transfert de fichiers TPS/TVH par Internet

Téléphone

Vous pouvez produire votre déclaration de TPS/TVH par téléphone en utilisant le service IMPÔTEL TPS/TVH de l’ARC.

Cette méthode nécessite un code d’accès pour la TPS/TVH.

Apprendre comment produire

Par téléphone à l’aide d’IMPÔTEL

Poste

Vous pouvez produire votre déclaration par la poste en envoyant votre déclaration papier (formulaire GST34-2, GST62 ou RC7200) à l’adresse figurant sur la déclaration.

Pénalité possible si vous produisez par la poste

On vous imposera une pénalité si vous produisez votre déclaration par la poste, à moins que vous soyez un organisme de bienfaisance, une institution financière désignée particulière ou que vous ayez une exemption.

Apprendre comment produire

En envoyant une déclaration papier par la poste

Si vous avez besoin d’un code d’accès

Si vous prévoyez produire votre déclaration à l’aide du formulaire IMPÔTNET, d’un logiciel tiers ou d’IMPÔTEL, vous aurez besoin de votre code d’accès à 4 chiffres.

Apprenez comment obtenir un code d’accès pour la TPS/TVH au besoin.
