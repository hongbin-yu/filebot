Alertes d'information

Retrouvez l’accès à votre compte de l’ARC sans avoir à nous appeler

Les utilisateurs dont le compte de l’ARC a été verrouillé parce qu’ils ont oublié leur justificatif d’identité peuvent maintenant s’inscrire de nouveau pour en obtenir un autre et retrouver l’accès à leur compte. Pour en savoir plus, allez à S’inscrire à un compte de l’ARC.

Lancement de l’authentification multifacteur de secours

Au moment de vous connecter à votre compte de l’ARC, nous vous demanderons d’ajouter une option d’authentification multifacteur de secours si vous n’en avez pas déjà une. Vous pourrez sauter cette étape pendant la période des impôts.

Recours collectif Sweet (service CléGC) :

Le 31 mars 2026, la Cour fédérale tiendra une audience pour décider si elle approuvera l’accord de règlement proposé dans le cadre du recours collectif Sweet. Apprenez-en davantage sur le règlement proposé.

Avis par courriel – Passez au courrier électronique avec l’ARC

Il se peut que vous ayez récemment reçu un avis par courriel de l’ARC. Afin d’offrir un service plus rapide et fiable, l’ARC encourage les utilisateurs du compte de l’ARC à modifier leur préférence de correspondance pour passer du courrier papier au courrier électronique. Cela permet de vous garantir une livraison sécurisée et ponctuelle des communications importantes, tout en évitant des retards liés à une interruption des services postaux ou des catastrophes naturelles.

    Connectez-vous en utilisant vos justificatifs d’identité existants :

    Avant de vous connecter

    Se connecter au nom d’une autre personne

    Si vous vous connectez au nom d’une autre personne (y compris un ami ou un membre de votre famille), vous devez utiliser Représenter un client à partir de votre compte de l’ARC pour accéder à ses informations.

    N'utilisez pas le remplissage automatique sur un appareil partagé

    N'utilisez pas le remplissage automatique pour entrer vos renseignements bancaires en ligne si vous utilisez un appareil partagé. Lorsque vous êtes sur le site Web de votre partenaire de connexion, assurez-vous que ce sont vos informations qui sont saisies et non celles de quelqu'un d'autre.

    Si vous vous inscrivez en utilisant les justificatifs d'identité bancaires de quelqu'un d'autre par erreur et que vous y associez votre NAS, l'autre personne aura accès à vos renseignements fiscaux.

Aide supplémentaire concernant l'ID utilisateur et le mot de passe de l'ARC

Vous n’avez pas reçu de code d'accès à utilisation unique

Essayez les options suivantes pour obtenir votre code d’accès à utilisation unique :

  • demandez que le code d'accès soit renvoyé ou envoyé à un autre numéro de téléphone avec lequel vous êtes déjà inscrit
  • utilisez l’option appelez-moi au lieu de envoyez-moi un message texte si vous utilisez un service de voix sur IP
  • utilisez la grille de codes si vous êtes déjà inscrit avec cette option
  • utilisez l’application d’authentification tierce si elle est déjà configurée

Si aucune de ces options n’est disponible pour vous ou si vous ne pouvez toujours pas recevoir votre code d’accès à utilisation unique, vous devrez nous contacter.

Aide supplémentaire concernant l'authentification multifacteur

Vous n’avez pas reçu votre code de sécurité de l’ARC

Si votre code de sécurité de l’ARC a été perdu ou n’est pas arrivé après 10 jours ouvrables vous pouvez soit :

  • utiliser le service de vérification des documents pour faire vérifier votre identité
  • nous contacter pour en obtenir un nouveau par la poste

Si votre code de sécurité de l’ARC a expiré, vous pouvez soit :

  • utiliser le service de vérification des documents pour faire vérifier votre identité
  • vous connecter pour demander à en obtenir un nouveau par la poste
Mettre à jour vos renseignements auprès de l’ARC

Informez l’ARC des changements apportés à vos renseignements sur le dépôt direct ou vos renseignements personnels tels que votre adresse, votre numéro de téléphone ou votre nom.

Si votre ID utilisateur et votre mot de passe de l’ARC ont été révoqués, vous pouvez récupérer l’accès à votre compte de l’une des façons suivantes :

  • Utiliser une autre option de connexion.
  • Repasser par le processus d'inscription pour obtenir un nouvel ID utilisateur et mot de passe de l’ARC.

Aide supplémentaire concernant la révocation de l’ID utilisateur et du mot de passe de l’ARC

Changer votre option de connexion

Si vous vous êtes inscrit à l’aide d’un partenaire provincial, vous pouvez aussi créer un ID utilisateur et un mot de passe de l’ARC ou utiliser un partenaire de connexion.

Si vous vous êtes inscrit à l’aide d’un ID utilisateur et d’un mot de passe de l’ARC, vous pouvez vous connecter à l’aide de votre ID utilisateur et de votre mot de passe de l’ARC et révoquer vos justificatifs d’identité afin de pouvoir vous inscrire à l’aide d’une autre option de connexion ou créer un nouvel ID utilisateur et un nouveau mot de passe de l’ARC.

Si vous vous êtes inscrit à l’aide d’un partenaire de connexion, vous pouvez vous connecter à l’aide de votre partenaire de connexion actuel et le changer pour un autre partenaire de connexion.
