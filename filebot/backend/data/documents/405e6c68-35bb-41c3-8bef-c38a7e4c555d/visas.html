Visas, biométrie et autorisations de voyage électroniques Les exigences d’entrée varient d’un pays à l’autre. Avant de partir, vous devez savoir ce dont vous avez besoin pour entrer dans le pays de destination, comme les visas, les autorisations de voyage électroniques ou vos données biométriques. Sur cette page Visas Biométrie Autorisations de voyage électroniques Visas Un visa est un document officiel, habituellement estampillé ou collé à l’intérieur d’un passeport, qui permet à un ressortissant étranger d’entrer dans un pays dans un but précis et pour une durée déterminée. Découvrez si vous avez besoin d'un visa Pour savoir si vous avez besoin d’un visa pour votre voyage, commencez par consulter notre page Conseils aux voyageurs bien avant votre départ. Sélectionnez votre destination dans le menu déroulant et consultez les renseignements sur les visas dans la rubrique « Exigences d’entrée et de sortie ». Vous devez ensuite communiquer avec l’ambassade ou le consulat de votre destination situés au Canada pour vérifier si vous avez besoin d’un visa pour entrer dans le pays ou pour y séjourner plus longtemps. Obtenir un visa Les visas sont délivrés par les bureaux des gouvernements étrangers au Canada. Les exigences, les frais et les délais de traitement varient en fonction du pays et du type de visa dont vous avez besoin. Les catégories les plus courantes sont les visas d’affaires, de travail, d’étudiant et de tourisme. Informez-vous en consultant les Conseils aux voyageurs pour votre destination. Rappelez-vous que les représentants de votre pays de destination doivent voir votre passeport avant de vous délivrer un visa. Si vous ne pouvez pas vous rendre dans un bureau du gouvernement étranger en personne et que vous devez envoyer votre passeport par courrier, choisissez un service postal sécuritaire et joignez une enveloppe-réponse affranchie à votre demande. Exigences Avant de partir, vous devez également confirmer certains renseignements précis en fonction de votre situation et de votre destination : Durée du séjour : Si vous avez l’intention de rester dans un pays étranger pendant une longue période (généralement plus de 90 jours), vous aurez très certainement besoin d’un visa et vous devriez consulter les Conseils aux voyageurs pour votre destination pour le confirmer. Passeports spéciaux : Les titulaires de passeports spéciaux et diplomatiques doivent vérifier toutes les exigences en matière de visa pour chacune de leurs destinations, car ces exigences peuvent différer de celles qui s’appliquent aux titulaires de passeports réguliers. Visas à l’arrivée : Certains pays délivrent un visa à l’arrivée, mais ce n’est pas une procédure courante. En général, les visas doivent être obtenus avant de quitter le Canada. L’entrée peut vous être refusée si vous n’avez pas de visa à votre arrivée dans un pays qui en exige un. Consultez les Conseils aux voyageurs pour votre destination pour vous en assurer. Pages du passeport réservées aux visas : Il vous incombe de veiller à ce que votre passeport contienne des pages vierges pour les visas. Si les pages de votre passeport sont remplies de visas ou de tampons d’entrée et de sortie, demandez un nouveau passeport. Renouveler mon visa Pour prolonger votre séjour dans un pays au-delà de la période autorisée par le visa que vous détenez, ou pour modifier le statut de votre visa (par exemple, pour passer d’un visa de tourisme à un visa de travail), veuillez communiquer avec les autorités d’immigration de votre destination pendant que vous êtes dans le pays. Biométrie Certains pays exigent que votre photo ou vos empreintes digitales soient prises par les autorités à votre arrivée au point d’entrée. Ces mesures permettent d’établir un dossier numérique qui enregistre vos données biométriques et remplace généralement la nécessité de tamponner votre passeport. La durée de validité de votre dossier numérique est définie par chaque pays. Sachez qu’il peut vous être demandé de fournir à nouveau vos données biométriques, même si vous vous êtes rendu récemment dans le pays de destination. Pour savoir si les données biométriques sont une exigence d’entrée dans le pays où vous prévoyez vous rendre, vérifiez les exigences d’entrée et de sortie dans les Conseils aux voyageurs pour votre destination. Autorisations de voyage électroniques Certains pays exigent que les voyageurs exemptés de visa obtiennent une autorisation de voyage électronique (AVE) avant d’entrer sur leur territoire. Ce document numérique, qui peut être obtenu en ligne, constitue une mesure de sécurité et un premier contrôle. Pour savoir si vous avez besoin d’une AVE pour entrer dans les pays où vous vous rendez, consultez les conditions d’entrée et de sortie pour votre destination dans nos Conseils aux voyageurs et avertissements.
