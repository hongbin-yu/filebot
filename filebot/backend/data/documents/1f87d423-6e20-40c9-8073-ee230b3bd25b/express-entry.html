Express Entry Express Entry is an online system that we use to manage immigration applications from skilled workers. There are 3 immigration programs managed through Express Entry: Canadian Experience Class Federal Skilled Worker Program Federal Skilled Trades Program How the Express Entry process works: Create a profile and enter the pool. We'll invite the candidates with the most points in rounds. If you're invited to apply, fill out the application. We'll review your application and make a decision.
