🌾 Department Import Tool

Import department website content into FileBot page by page. Runs directly in the browser, zero deployment.

📌 Bookmarklet (No External Load)

Drag to your bookmarks bar. Click it on any canada.ca page — works instantly because all the code is inside the bookmark itself. No requests to external servers. Recommended

👇 Drag to bookmarks bar

🌾 Import

Then go to any canada.ca page → click "🌾 Import" in your bookmarks bar

📋 Setup Steps

  1. Show your bookmarks bar (Chrome: Ctrl+Shift+B / Cmd+Shift+B)
  2. Drag "🌾 Import" above to your bookmarks bar
  3. Navigate to any canada.ca page
  4. Click 🌾 Import
  5. Enter the API URL and token, then click Start

🔧 FileBot API Configuration

The tool will POST the page HTML to your FileBot instance. Make sure it's reachable from your browser (e.g. http://localhost:8001 for local dev).

Default API URL: http://localhost:8001/api/v1/import-page

Getting an API Token

curl -X POST http://localhost:8001/api/v1/auth/login \ -H "Content-Type: application/x-www-form-urlencoded" \ -d "username=admin&password=admin123"

Copy the access_token from the response and paste it into the tool's token field. Prefix with Bearer if needed.
