PCL转换工具安装指南

GhostPCL安装

GhostPCL是Artifex提供的专业PCL解释器，包含在Ghostscript商业版中。

  1. 访问 Artifex下载页面
  2. 下载Ghostscript商业版（包含GhostPCL）
  3. 安装并添加gpcl6.exe到系统PATH
  4. 验证安装：gpcl6 --version

WSL/Ubuntu安装

在WSL环境中安装相关工具：

sudo apt update
sudo apt install -y hplip ghostscript
# 检查可用工具
find /usr -name "*pcl*" -type f 2>/dev/null | head -10

手动配置工具路径

如果工具不在系统PATH中，可以手动配置：

  1. 在应用目录创建.env文件
  2. 添加配置：PCL_TOOL_PATH=/path/to/your/tool.exe
  3. 或使用PCL_TOOL_PATH=auto自动检测
