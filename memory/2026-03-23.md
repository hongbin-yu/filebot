### 🔍 **错误诊断**:

#### **日志分析结果**:
1. **错误类型**: Pydantic ValidationError
2. **具体错误**: 
   ```
   ValidationError: 1 validation error for PageResponse
   metadata
     Input should be a valid dictionary [type=dict_type, input_value='{}', input_type=str]
   ```
3. **根本原因**: 数据库存储`metadata`字段为JSON字符串`'{}'`，但Pydantic模型期望字典类型`{}`

#### **技术分析**:
- **数据库存储**: SQLite将JSON字段存储为TEXT类型 (`'{}'`)
- **模型期望**: Pydantic的`PageResponse.metadata`字段类型为`Optional[Dict[str, Any]]`
- **类型不匹配**: 字符串`'{}'` vs 字典`{}` → 验证失败 → 500错误

### 🛠️ **修复实施**:

#### **修复文件**: `/home/hongb/.openclaw/workspace/webbot/app/routes/pages.py`

#### **修复内容**:
1. **添加json导入**: `import json`
2. **create_page端点修复**: 添加metadata字段解析逻辑
   ```python
   if result.get("metadata") and isinstance(result["metadata"], str):
       try:
           result["metadata"] = json.loads(result["metadata"])
       except json.JSONDecodeError:
           result["metadata"] = {}
   elif result.get("metadata") is None:
       result["metadata"] = {}
   ```

3. **list_pages端点修复**: 为每个页面添加相同解析逻辑
4. **get_page端点修复**: 添加相同解析逻辑

#### **修复原理**:
- **自动转换**: 从数据库读取时自动将JSON字符串转换为字典
- **错误处理**: 如果JSON解析失败，使用空字典作为默认值
- **向后兼容**: 确保所有API端点返回一致的数据类型
