- **bcrypt 版本问题**：Passlib 与 bcrypt 库版本不兼容

- **解决方案**：改用`pbkdf2_sha256`哈希方案作为临时解决方案
- **实现**：修改`app/core/security.py`中的`CryptContext`配置：
  ```python
  pwd_context = CryptContext(
      schemes=["pbkdf2_sha256"],
      pbkdf2_sha256__default_rounds=30000,
      deprecated="auto"
  )
  ```
- **密码长度保护**：添加了密码长度检查，超过72字节时自动截断并记录警告
