const calculateAlignmentFromX = (x: number): 'left' | 'center' | 'right' => {

  if (x < centerZone) return 'center';
  return 'right';
};

### 📋 **官方定位系统解析**:

#### **核心定位机制**:
1. **双重坐标系统**:
   - **X轴位置**: `pstn-lft-*` (左对齐系列) 和 `pstn-rght-*` (右对齐系列)
   - **Y轴位置**: `pstn-tp-*` (顶部对齐) 和 `pstn-bttm-*` (底部对齐)
   - **必须同时定义**: "both the x and y position must be defined" (X和Y位置必须同时定义)

2. **响应式设计集成**:
   - 定位系统与网格系统协同工作
   - 小屏幕时线性化: "When the grid system linearizes for smaller viewports, so does the positioning"
   - 定位随视口大小变化而响应式调整

3. **CSS工具类系统**:
   - 使用预定义的CSS工具类进行定位
   - 例如: `pstn-lft-sm`, `pstn-rght-md`, `pstn-tp-lg`, `pstn-bttm-sm`
   - 支持不同断点 (sm, md, lg, xl)

4. **绝对定位用途**:
   - "Use to position content on top of other content"
   - "Use to control the content position on a page"
   - 主要用于覆盖层、悬浮元素、精确位置控制

## 🔄 **编辑器横向滚动问题修复** (2026-03-26 16:15 UTC)

### 🎯 **用户反馈**:
- **时间**: 2026-03-26 12:06 EDT (16:06 UTC)
- **反馈内容**: "现在好多了，编辑器只有上下滚滚动，没有横向滚动，可能要加上去"
- **问题现象**: 编辑器画布区域只有垂直滚动条，缺少水平滚动条

- **画布区域**: `overflowX: 'auto'`, `overflowY: 'auto'` (已设置但可能被父容器限制)

- **CSS继承**: `overflow: hidden` 在父容器会覆盖子容器的滚动设置

```typescript
// 之前 ❌

// 现在 ✅
overflowX: 'auto',
overflowY: 'auto',
minWidth: '100%',  // 确保容器宽度至少占满父容器
```

- **EditorCanvas组件**: `overflow: 'visible'` (允许子元素溢出)
- **画布区域**: `overflowX: 'auto'`, `overflowY: 'auto'` (显式水平和垂直滚动)
- **最小宽度**: `minWidth: '100%'` (强制占满可用空间)
