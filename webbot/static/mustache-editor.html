Mustache Syntax Reference

  • Variables: {{variableName}} - inserts the value
  • Sections: {{#array}}...{{/array}} - loops through an array
  • Inverted Sections: {{^array}}...{{/array}} - shows if array is empty
  • Partial Templates: {{> partialName}} - includes another template
  • Comments: {{! This is a comment }} - not rendered

Data source should return JSON. Arrays will be iterated, objects will have their keys available.
