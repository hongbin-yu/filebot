Our Products

Three Products, One Ecosystem

WebFileBot delivers a complete content lifecycle solution — from ingestion and editing to publishing and monitoring.

🌐

WebBot — Content Engine →

A powerful web content management and editing suite designed for Canada.ca and government publishing standards.

  • Intelligent web crawling & bulk ingestion
  • WET4-compliant visual page editor
  • Tag & metadata management with hierarchical trees
  • Version control with rollback and diff
  • AI-powered multi-replace and batch operations
📁

FileBot — Document Backend →

A high-performance document management and API backend that powers all content storage, search, and delivery.

  • PostgreSQL-backed document storage
  • Full-text search across documents
  • REST API with auto-generated TypeScript client
  • Thumbnail generation & CDN fallback
  • App integrations and custom workflows
📊

AnalyBot — Analytics Platform →

A self-hosted analytics platform powered by ClickHouse. Tracks pageviews, clicks, scroll depth, forms, and performance — zero external data leakage.

  • JavaScript SDK for browser auto-tracking
  • ClickHouse real-time event storage
  • Department & section segmented breakdowns
  • Live Dashboard with aggregated metrics
  • Canadian data residency — Bill C-27/PIPEDA compliant
