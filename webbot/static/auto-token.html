🚀 Auto Token for FileBot API Docs

What this does: Automatically gets a valid JWT token and helps you use it in FileBot's Swagger UI.

How to use:

  1. Click "Get Token" below to fetch a fresh token
  2. Copy the token (or use "Copy Token" button)
  3. Go to FileBot API Docs
  4. Click the "Authorize" button
  5. Paste the token with "Bearer " prefix
  6. OR use "Auto Fill" button to try automatic setup

Your Token:

Expires in: seconds

Full Authorization header:

Bearer

Token Information:

Token Source: WebBot Backend API

Auto-refresh: Token is automatically refreshed before expiration

Default User: admin (FileBot superuser)

Token Lifetime: 30 days (configurable in FileBot .env)
