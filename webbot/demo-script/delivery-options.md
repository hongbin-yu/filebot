# 演示方案选择 — 三种交付方式

**项目：** Canada.ca RFP Demo Video
**日期：** 2026-07-06

---

## 方案 A — 真人配音旁白（Human Voiceover）

**流程：**
1. 屏幕录制软件录画面（无声音）
2. 专业配音演员/团队负责人按旁白稿录音
3. 后期将音画对齐、剪辑

**优缺点：**
| ✅ 优点 | ❌ 缺点 |
|---|---|
| 声音自然、有情感起伏 | 需要约配音演员/费用 |
| 可控制语速、重音、停顿 | 录制周期较长 |
| 专业感最强 | 多人协调时间 |
| 适合正式RFP提交 | 修改旁白需重新录制 |

**建议场景：** 如果追求最高质量，且预算允许（约$200-500 CAD 配音费）

**已有材料：** `audio/voiceover-script.txt` — 完整的旁白稿，配音演员可直接用

---

## 方案 B — AI 配音旁白（AI Voiceover）✅ 已生成

**流程：**
1. 屏幕录制软件录画面（无声音）
2. 用已生成的 AI 音频直接放入视频
3. 必要时可重新生成调整

**优缺点：**
| ✅ 优点 | ❌ 缺点 |
|---|---|
| ✅ 已生成完毕，立即可用 | 语调略显机械（Liam Neural 已经很好） |
| 零成本 | 缺少真人情感变化 |
| 不限次数修改 | 复杂的语气/幽默难以表现 |
| 15段按场景分好，剪辑直接拖入 | |
| Canada.ca 标书，专业感足够 | |

**建议场景：** 快速出片、预算有限、或团队负责人自己没时间录音

**已有材料：** 
- `audio/scene-*.mp3` — 15段按场景分好
- `audio/voiceover-full.mp3` — 整段合辑

---

## 方案 C — 现场演示指南（Live Presenter Guide）🆕 需新写

**形式：**
- 不是视频，是 **PPT + 旁白手卡**
- 评审会上，团队负责人现场打开系统演示
- 每张 PPT 对应一段实际系统操作

**准备材料：**
- PPT 我们已经有了（21页）
- 需要额外写一份 **Presenter's Script** — 每张 PPT 对应：
  - 屏幕操作说明（在哪个页面/做什么）
  - 讲者要说的话（类似旁白稿但更口语化）
  - 注意事项/踩坑提醒
  - 时间控制建议

**优缺点：**
| ✅ 优点 | ❌ 缺点 |
|---|---|
| 真人现场演示，可信度最高 | 必须预约评审时间 |
| 可互动、可回答提问 | 演示者需要排练 |
| 系统卡顿可灵活跳过 | 现场有翻车风险 |
| 评审可以实时提问 | 时间控制更难 |
| 成本最低（只需要排练时间） | |

**建议场景：** 如果 RFP 允许现场演示，且团队有自信的演示者

|---|---|---|---|

| 成本 | $200-500 | $0 | $0（时间成本） |
