## Scene 4 — Data Migration Demo: Bookmarklet Single Page (1.5min)

**Screen:** Browser opens a legacy Canada.ca page

* Mouse clicks Bookmarklet in browser bookmarks bar
* Page content is automatically captured
* Switch to Webbot — new page is already created
* Show auto-populated title, content, metadata

**Voiceover:**

> "Now let me show you data migration in action. We have two approaches: bulk import via sitemap — which we just covered — and single-page migration using our Bookmarklet tool.
>
> Here I am on an existing government page. I simply click the Bookmarklet in my browser — watch closely.
>
> And just like that, the entire page — title, content, metadata — has been captured and imported into Webbot. The structure is preserved, nothing is lost.
>
> This is how we make migration painless. No manual copy-paste. No data loss. Just click and go."

## Scene 5 — Webbot CMS: Full Editing Workflow ⭐ (5min)

**Screen:** Webbot admin interface

**Voiceover:**

> "Now let's get into the heart of the platform — Webbot CMS. I'll walk you through the complete content lifecycle, from creation to publication."

### 5a — Create a Page (30s)

**Screen:** Click "New Page", enter title, select path, choose language, pick a template

**Voiceover:**

> "Creating a new page is straightforward. Give it a title, choose your language, pick a template — and we're ready to go. We have over 10 templates to choose from, each purpose-built for different content types."

### 5b — Edit Page: Add a Component (1min)

**Screen:** Enter the editor, show the Component panel (100+ components displayed in a grid)

* Drag a component into the page area

**Voiceover:**

> "Here's where Webbot truly shines. We have over 100 components — and unlike Adobe's platform where you're limited to about a dozen, our components have no boundaries.
>
> What does that mean? Any combination of elements can become a component. Text, images, videos, structured data — you name it.
>
> Adding one is as simple as drag and drop. And because our components are built on HTML Mustache templates plus API configuration, anyone — a publisher, a designer — can create new components. No developer required.
>
> To put this in perspective: Adobe has had about 10 components and 7 templates in over a decade, and most of them aren't even in use. Their teams end up relying on a single Generic HTML component for everything. That's not flexibility — that's a bottleneck."

### 5c — WYSIWYG In-Place Editing (1min)

**Screen:** Click text directly on the page preview — text becomes editable

* Edit the text
* Format it
* No pop-ups, no modals

**Voiceover:**

> "This is what we call What You See Is What You Get — and What You See Is What You Edit.
>
> Want to change a heading? Just click on it. Edit it right here. No pop-ups, no modal windows, no context switching between edit mode and preview mode.
>
> With Adobe, editors constantly toggle between views and fight with pop-up dialogs. Our approach is simple: you see the page exactly as it will appear, and you edit it in place. It's faster, more intuitive, and editors love it."

### 5d — Add Image + Drag \& Drop (1min)

**Screen:**

* Open the asset library from FileBot
* Drag an image into a component on the page

**Voiceover:**

> "Adding images is just as seamless. Open the asset library, find your image — and drag it directly into the page. No upload dialogs, no file pickers, no separate save steps.

**Voiceover:**

## Appendix: Production Notes

### Staging Environment Requirements

* Fully deployed Webbot + FileBot + AnalyBot
* At least 2-3 editable test pages with content
* One test image ready for drag-and-drop demo
* Bookmarklet configured targeting a legacy page
* AI features deployed and accessible (Q\&A, Assistant, Translation, Image Tagging)

### Recording Recommendations

* Screen recording: 1920x1080, 60fps
* Voiceover: professional microphone recommended (or AI voice-over for post-production)
* Comparison table: animate rows appearing one by one for impact
* Target runtime: under 12 minutes

### Post-Production Suggestions

* Optional background music (subtle, professional)
* Key data points highlighted with text animation
* Subtitles (English + French if desired for bilingual audience)
