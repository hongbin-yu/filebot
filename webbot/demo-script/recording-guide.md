# 录屏操作指南 — Scene-by-Scene 录制分步清单

**配合音频使用：** 每段音频播放，同时按以下步骤操作屏幕。
**策略说明**
- **⏱️ 无声前奏（每段开头 1-3秒）**：音频开始前先让画面动起来，不要让人看到静止画面
- **🎯 关键操作推荐用 OBS 录制**：窗口捕获 + 鼠标高亮（Highlight cursor）

## 附录：录制前检查清单

### 环境准备
- [ ] FileBot 已登录（建议提前登录）
- [ ] Webbot 已登录，至少 2 个可编辑页面
- [ ] AnalyBot 有数据可展示
- [ ] Bookmarklet 已在浏览器书签栏
- [ ] 旧网站页面已打开（作为迁移源）
- [ ] AI 功能均已部署可用（Q&A, Assistant, Translation, Tagging）
- [ ] 测试图片已上传到 FileBot

### 录屏设置
- [ ] OBS / Camtasia / QuickTime
- [ ] 1920×1080, 30fps 足够
- [ ] 鼠标高亮开启（推荐 OBS 的 Cursor Highlight 插件或系统设置）
- [ ] 关闭所有通知弹窗（系统、浏览器）
- [ ] 浏览器全屏，去掉书签栏（F11）—— 除了 Scene 04 需要展示 Bookmarklet

### 音频同步技巧
- **播放音频时监听耳机**，同时对着画面操作
- 可以在 OBS 中把音频轨和画面轨分开录，后期更容易调整
- 每个场景录完后留 2 秒静帧，方便剪辑

### 如果录错了
- 不用重头录！记下**从哪个时间点**开始重来
- 剪辑师可以把正确的片段拼上去
- 优先保证每个场景内的操作连贯
