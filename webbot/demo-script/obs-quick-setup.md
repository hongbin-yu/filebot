# OBS 快速设置指南 — 录屏够用版

## 第一步：建 1 个 Scene（一个就够）

1. 打开 OBS
2. 左下角 **Scenes** 框 → 点 **+** → 输入名字 `Demo` → OK

![示意] Scene 框在左下角

---

## 第二步：添加画面源（Sources）

1. 中间 **Sources** 框 → 点 **+** → 选 **Window Capture**（窗口捕获）
2. 弹出窗口：
   - **Create new:** `浏览器` → OK
   - **Window:** 选你录屏的浏览器窗口（Chrome/Edge）
   - ☑️ Capture cursor ✅（捕获鼠标指针）
   - ☑️ 下面其他选项保持默认 → OK

这时候 OBS 中间应该已经显示你的浏览器画面了。

---

## 第三步：设音频

1. 右下角 **Settings**（设置）→ **Audio**（音频）
2. 确保：
   - **Desktop Audio**（桌面音频）= 默认设备（或 Speakers）
   - **Mic/Auxiliary Audio** = 你的麦克风（如果你想加口播）
3. → OK

如果你只需要画面（不录口播），桌面音频开着就行。

---

## 第四步：设画质

**Settings → Output（输出）→ Output Mode 选 Advanced（高级）**

然后切到 **Recording（录像）** 标签：

| 设置项 | 推荐值 |
|---|---|
| **Encoder（编码器）** | 如果 Nvidia 显卡选 `NVIDIA NVENC H.264` / AMD 选 `AMD HW H.264` / 都没有选 `x264` |
| **Rate Control** | `CQP`（质量优先） |
| **CQ Level** | `20`（越小编号越小，18-23 范围，20 很不错） |
| **Format（格式）** | `mp4` |
| **Recording Path** | 点 Browse，选一个文件夹存视频，比如桌面 `C:\Users\...\Desktop\demo-recordings` |

**Settings → Video（视频）:**

| 设置项 | 推荐值 |
|---|---|
| **Base (Canvas) Resolution** | 你的显示器分辨率（通常是 1920×1080） |
| **Output (Scaled) Resolution** | `1920×1080` |
| **Common FPS Values** | `30`（30帧足够，文件小） |

→ OK

---

## 第五步：加鼠标高亮（重要！）

CMS 演示一定要让人看清你在点哪里：

1. **Sources** 框 → **+** → 选 `Add` → 搜索安装插件（略麻烦）

或者用**最简单的方法**：打开 Windows **设置 → 蓝牙和其他设备 → 鼠标 → 指针和触摸 → 指针轨迹 → 开启**

更简单：用 **dvtCursor** 或 **MousePointer** 这类免费小工具。

如果不想装任何东西 → **录的时候鼠标动慢一点、大一点**就好了，Windows 自带的可调鼠标大小（设置 → 鼠标 → 鼠标指针样式 → 调大）。

---

## 第六步：开始录制

1. 打开你要录的**浏览器页面**
2. 在 OBS 里确认画面显示正确
3. 准备播放 AI 旁白音频（手机/另一台电脑播放）
4. 点击 **Start Recording**（开始录制）→ 右下角或顶部菜单
5. 开始操作 → 音频同步播放
6. 完成 → 点 **Stop Recording**

视频会自动存到你设置的文件夹。

---

## 每段场景的录制姿势

```
┌─────────────────────────────────────────────┐
│  一个场景录一段，不要整场连着录              │
│                                              │
│  原因：哪段录砸了只重录那一段                │
│                                              │
│  1. Start Recording                          │
│  2. 静等 2 秒                                │
│  3. 播放音频（手机外放或耳机听着）            │
│  4. 按录屏操作清单操作                        │
│  5. 停 2 秒 → Stop Recording                 │
│  6. 命名文件 scene-03-filebot.mp4            │
│  7. 接着下一段...                             │
└─────────────────────────────────────────────┘
```
